3指纹软件交付三种模式

a. 自研项目

Moto 基线代码。Moto 自行拉取基线指纹代码，无需我们提供代码，由 Moto 研发维护。

b. ODM 2

与 Moto 共线，不能随意修改。拉取 Moto 基线代码进行调试，无需我们提供代码。

c. ODM 1

软件完全由 ODM 负责，使用我们的原生代码，需要我们提供代码。

交付差异要点：是否需要提供原生代码，取决于项目属于自研 / ODM 2（均走 Moto 基线）还是 ODM 1（用我们的原生代码）。

4基线代码集成

  • MOTO 产线测试工具 cqatest
  • CPU boost

5Moto 软件客制化

a. 录入策略（电容指纹）

  • 总次数 32 次 = 20 张成功接受的图 + 12 次卡重
  • 从第 5 次开始卡重，卡重点为第 5、9、11、13、15、17 次
  • 最多连续两次卡重，第三次将强制录入

卡重次数示意（橙色为卡重点）：

1234 5678 910 1112 1314 1516 17181920

b. 二维码检测（电容 / 光学指纹）

读取并解码 OTP 二维码信息。

c. Sensor Damage Check

检测 Sensor 硬体异常并下电，同时将结果写入 prop。

6产线测试项（整机端）

#STT Test ItemsFunction

3 image_quality_test 需按压手指采集图像，以判定 SNR 信噪比

11软件释放规范

释放流程要求

  1. 提供 patch 给客户时，必须写好 Release Note，并附上必要的测试报告
  2. Release Note 应包含：
    • 项目分支名 - 版本号
    • 释放时间
    • 修改文件
    • 解决的问题
  3. 做好记录存档
